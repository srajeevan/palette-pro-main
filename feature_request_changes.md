# Feature Request Changes

Changes made in response to user feedback and feature requests.

---

## No More Pure Black Mixes
**Date:** 2025-04-22
**Source:** User feedback — "No black. A lot of painters don't use black, myself included."

**What changed:**
- Removed Ivory Black and Mars Black from the mixing engine entirely
- Dark colors are now mixed using chromatic pigments like Burnt Umber + Ultramarine Blue, Phthalo Blue + Burnt Sienna, or Payne's Gray
- No more impractical ratios like "1 part Phthalo Green + 57 parts Ivory Black"
- Payne's Gray (a blue-gray) is still available as a chromatic dark option

**Why:**
Many oil painters avoid pure black because it makes paintings look flat and lifeless. Chromatic darks mixed from complementary colors produce richer, more vibrant shadows — and are much easier to mix on the palette.

**User-facing note:**
Dark colors now use chromatic mixes instead of pure black — richer shadows, practical ratios, and no more "dead" darks on your canvas.
